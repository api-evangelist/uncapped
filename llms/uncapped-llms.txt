# Uncapped

> Uncapped provides working capital to online businesses - merchant cash advances (MCA), term loans, and lines of credit (LOC). The Uncapped Partners API lets platforms embed lending directly into their product: authenticate a backend with a signed JWT, submit anonymised applicant performance data, generate pre-offer estimations (individually or in batch), fetch display-ready funding Signals, and react to application and estimation lifecycle events via webhooks.

Generated by API Evangelist from the Uncapped Developer Hub and published OpenAPI (no provider llms.txt found; the Developer Hub serves its SPA shell at /llms.txt).

## Key semantics

- Auth: POST /partner/authentication/token exchanges a signed partner JWT for a short-lived bearer access token.
- Pagination: zero-based page/size/sort parameters; responses envelope content/page/size/totalElements/totalPages.
- Errors: application/json envelope {message, code, details[{code, message, fieldName}]}.
- Webhooks: API-managed subscriptions for APPLICATION_STATUS_CHANGED, ESTIMATION_EXPIRED, ESTIMATION_BATCH_COMPLETED.
- Data conventions: ISO 8601 dates, ISO 4217 currencies, ISO 3166-1 alpha-3 countries, ISO 3166-2 states.
